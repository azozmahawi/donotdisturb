How to start a game

  • Both players need their own iPhone with Do Not Disturb installed.
  • Both players must be signed in to Game Center (Settings › Game Center).
  • One player taps Host a game. A 6-digit code appears.
  • The other player taps Join a game and types in that code.
  • Each of you picks a detective, types a name, and the host taps Start.

We can't connect

  • Check that both phones are online and signed in to Game Center with different accounts.
  • Make sure both phones have the latest version of the game from the App Store.
  • Check that the code was typed exactly, then try hosting again.
  • Still stuck? Close the game on both phones and open it again.

We're stuck on a puzzle

  • Tap the ⓘ button next to the room name to see your current goal.
  • Talk about everything you can see. Each detective has half of the answer.
  • Tap things more than once. Some objects say more the second time.
  • Tap an item in your bar twice to look at it more closely.

My partner left the game

If one player leaves, the game ends for both. Head back to the menu, host a new game, and pick the chapter you were on. Chapters you've reached stay unlocked.

Can I play alone?

No. Do Not Disturb is built for two players on two phones. Every puzzle needs both detectives.
